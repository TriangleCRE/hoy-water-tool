Tenant statements

A statement gathers every unpaid bill for a tenant (anything not marked Paid) into one PDF with a running total. Bills you mark Paid drop off automatically.
Method: the full City bill (water + sewer + tax) is split across the occupied tenants by each one's share of submeter usage, so the whole bill is recovered. Usage for each bill is pulled from the readings log; when the logged reads don't line up with the bill period it's marked estimated. Data auto-saves to the database and can be exported to a file. Invoices open in a print window — choose “Save as PDF”.
